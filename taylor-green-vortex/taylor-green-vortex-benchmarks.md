
Open CFD benchmark datasets generated using the **NumericalAI.net AI-Assisted GPU-Powered Simulations Platform**.

### Taylor Green Vortex, Re = 1600

A 3D Taylor–Green vortex dataset for turbulent decay and CFD model validation.

- Reynolds number: `1600`
- Grid resolution: `128 × 128 × 128`
- Domain: `[-π, π]³`
- Format: `HDF5`
- Approximate size: `16 GB`
- Generated with: `NumericalAI.net`
- License: `Apache-2.0`
- Hosting: `Hugging Face`

Due to the dataset size, the HDF5 files are hosted on Hugging Face instead of directly in this GitHub repository.

## Dataset Access

Large CFD datasets are hosted externally on **Hugging Face** for easier download, versioning, and distribution.

This GitHub repository provides:

- Dataset descriptions
- Metadata
- License information
- Usage notes
- Links to hosted dataset files

The full Taylor–Green vortex Re = 1600 dataset can be downloaded from Hugging Face once available.

## Dataset Format

Datasets are provided in **HDF5** format and may include:

- Velocity fields
- Pressure fields
- Vorticity fields
- Time-resolved simulation snapshots

Large datasets may be hosted externally due to GitHub file size limits.
